## Architectural Trade-offs & Decisions
- **Database:** Opted for SQLite over PostgreSQL. *Reason:* This is a localized internship project; SQLite requires zero external setup and stores data locally, satisfying requirements while maintaining simplicity.
- **Frontend:** Opted for Vanilla JS and Tailwind CDN over React/Next.js. *Reason:* The UI requirements are minimal (single page, form submission). A full build step for the frontend would unnecessarily bloat a backend-focused task.
